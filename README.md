# The 24-Inch Shelf

A single-page app for planning how a real book collection fits on a real bookshelf — sort 25 example books by title, author, year published, the year their story is set, thickness, or genre, and see them packed onto a 24-inch shelf, wrapping to additional shelves as needed.

## Run it

No build step. Just open `src/index.html` in a browser.
